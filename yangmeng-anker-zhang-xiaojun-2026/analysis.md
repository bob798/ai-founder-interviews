## I. 上帝视角：一个"好学生"的二次创业——在自己的公司里

这是八篇分析里**框架密度最高的一场访谈**。阳萌和肖弘（产业史类比者）、张鹏（政策窗口叙事）都不同——他是一个**职业抽象者**：每被问到一个具体问题，他先递给你一个自造的分类框架（1357 人群、浅海深海、三类公司、三层护城河、大牛人小牛人、养猪养马养娃），再把自己放进框架里定位。这既是他的思维方式，也是他承认的出身烙印："高考要考好成绩，你最好学会抽象。"

整场访谈的主轴是：**一家顺了 11 年的"五系公司"，在 2022 年撞上系统性失败（27 条产品线 20 条打不赢独角兽）之后，如何用"使命愿景价值观 + 深科技"完成二次创业**——而 AI 浪潮恰好叠加在这场转型之上。

## II. 12 个核心观点（按对受众的实操价值排序）

1. **1357 人群分层**：任何品类的消费者都分四群——一系买最便宜、三系买性价比、五系买品质稳定愿付溢价、七系买最贵最好（蜜雪冰城 → 一点点 → 沪上阿姨 → 喜茶）。安克前 10 年是五系公司，现在的转型是"从五系到七系"
2. **浅海 vs 深海，用德州扑克盲注理解**：深海=500 亿美金以上的超级品类（手机 5000 亿、PC 2000 亿），一注盲注 5 个亿，带 50 亿上桌打三五局就没了；浅海=规模小但饱和投入也小的一两百个中小品类。"浅"指规模小，不是简单
3. **第三类公司**：第一类做少量超级品类（苹果/特斯拉），第二类做少量中小品类（大多数公司），第三类**系统性做好几十个中小品类**（索尼、宝洁、耐克、德州仪器）——它要求"总统和联邦"的管理模式，而不是"国王和骑士团"
4. **流程阵法打不赢仗**：2022 年 27 条产品线 20 条打不赢外面的独角兽——教训是有流程型系统（IPD）不等于有战斗力，缺的是使命愿景价值观在人身上的映射
5. **创造者的三层特质**（从乔布斯/马斯克/内部创新者抽象）：怎么想事（第一性）× 怎么做事（求极致）× 怎么自处（长期主义 + 自我觉察 + 自我进化 = 共成长）
6. **计算范式转变：分治法 → 端到端**。前 80 年计算机是"冯诺依曼（存算分离）+ 分治法 + 程序"的稳定三角；端到端时代（数据学习 + 强化学习）这个三角应该被打破——每次推理要把全部参数从内存搬进 NPU，搬运本身就是最大功耗，"那我能不能不搬数据？"→ 存算一体
7. **模型分层如器官**：万亿参数=云端超级大脑，十亿到百亿=端侧（小脑），百万到千万=感知控制器官（视神经/肌肉神经）——未来世界不会由一个超级大脑控制，各器官跑与问题复杂度匹配的模型
8. **真智能三阶段**：不可调 → 可调节（马桶十几个按钮、人体工学椅——是"可调节"不是智能）→ 自己调节自己（感知/规划/控制）。自动驾驶最先跑通这三步，现在能力正外溢到家庭产品——所有"需要人调"的消费品都值得重做一遍
9. **技术护城河会撞上人类感知极限**：Retina 屏之后像素再密人眼分辨不出，充电器再小一半没有意义——技术优势放到足够长的时间里一定被抹平，之后靠品牌信任，最深处靠使命愿景价值观和相信它的人
10. **中层管理者不会因 AI 消失**：把一家公司讲清楚需要十亿到万亿 token 的 context，远超模型能力；压缩时"留什么不留什么"是价值选择，需要人。再加康威定律——组织形态决定产出，而组织是管理者用心血培育出来的
11. **大牛人造智能体，小牛人用智能体**：AI 时代组织=少量构建 AI 能力的人 + 大量高效使用智能体的人；企业级 AI 应是**预编排智能体**（沉淀成功流程和数据），而不是即时编排（现场编流程，临时且不稳定）
12. **创造者拿七、股东拿三**：一流公司总剩余价值约 30%，股东回报 10 个点算好公司门槛，剩下归创造价值的员工——AI 提效多出的利润也按这个比例分。配套数据：员工总收入连续两年年均 +20%，年薪百万人数 500 → 800 → 目标 1000

## III. 思想三层挖掘

### 【第一层：学科知识 — 阳萌的思想资源链路】

| 明确提到 | 用法 |
|----------|------|
| Google 工程文化（Jeff Dean 给他 code review） | 平等透明开放；"在别人创造的世界里做改进" |
| 华为 IPD（2019 年读相关书籍） | 把人的能力沉淀到组织，系统化做多品类 → 2020 组织变革 |
| 湖畔大学二期（2016） | "你的品类会变成千亿品类吗？"→ 对充电宝品类的死亡恐惧 |
| 冯诺依曼架构 / 分治法 | 计算范式转变论证的出发点 |
| 康威定律 | 组织形态决定产出 → 中层管理者论证 |
| 《有限与无限的游戏》 | 微软 vs 苹果 iPod 高管故事：盯竞争 vs 盯用户 |
| 乔布斯 1996 回归 | 两人群 × 两场景 = 四个产品坑位 |
| 拉姆·查兰《领导梯队》 | 人生之书："每个阶梯上该做什么不该做什么" |
| 马云"上楼"比喻 | 创业者从一层往三十层走，每层第一性都不同 |
| 佛教式自处（冥想） | 痛苦时的解法；自我觉察=先看见问题中自己的部分 |

**关键区分**：阳萌是八位嘉宾中**自造框架最多**的一位。他的思想资源一半来自工程训练（分治法、架构、抽象），一半来自管理经典（IPD、领导梯队、康威定律），几乎不引哲学家。他的方法是"看到惊艳的事物 → 抽象出底层原理 → 具象到各领域"——组织学习 spec 化工作流（他称之为流程智能体）如此，做芯片如此，回答访谈问题也如此。

### 【第二层：方法论 — 5 个可拆解的心智模型】

#### M1. 台阶论（踩稳一阶，够下一阶）

```
easy（电商卖货）→ medium（五系品质产品）→ hard（七系极致创新）→ nightmare（七系已有强者的品类，如耳机 vs AirPods）
```

- 与拓竹/大疆路径互为镜像：他们 day one 选地狱难度，打通后向下容易；安克从 easy 起步，现在"补课"
- 推论：起点难度是性格 × 时代的函数，没有绝对优劣，但**后半程都必须补上自己缺的那块**

#### M2. 双端锚定的品类扩张法

- 新品类要同时满足：与**现有人群**重叠度高（已买过你、信任你）+ 与**现有技术栈**重叠度高
- 两端都不重叠的扩张，"这脚跨出去大概率挑战比较大"——2022 年 27 条产品线的失败正是无锚扩张的代价

#### M3. 第一性链式推演（做芯片的完整逻辑链）

```
用户痛点（嘈杂环境通话不清）→ 需要百万级参数端到端模型 → 耳机芯片跑不动（搬参数=最大功耗）
→ 能不能不搬数据？→ 存算一体 → 全世界没有现成的 → 那就自己定制做一颗
```

- 关键特征：每一步都问"本质是什么"，缺的那块就是方向；"这个事情在公司层面并没有经过大量反复研讨"——价值观先行，推演自然得出结论

#### M4. 打仗次数论（人才成长模型）

- 人的成熟速度 ∝ 打仗次数。互联网一年打四仗 → 五年成熟 → 35 岁遇到下一波便宜的年轻人；硬件一仗一到两年 → 成长周期长 → 35 岁危机弱
- 推论（对个人择业）："考虑上限的时候一定要考虑自己的下限"——这是下限思考
- AI 修正：初级岗位消失不会断供高级岗位——建筑设计师古代从工匠升上来，现在直接学（校招生无编程经验用 AI 交付完整系统）

#### M5. 三到五档量表法（决策工具）

- 遇到二元问题先拉出光谱：赌性 = 1 分不投到 5 分加杠杆，他永远选 3（投过半但不全投）；公司观 = 养猪（卖）↔ 养马（伙伴+工具）↔ 养娃（作品）
- "中间"不是中庸：放进足够长的博弈里，稳定的 3 分 + 认知提升 = 复利通向成功

### 【第三层：底层哲学 — 阳萌的世界观结构】

#### 信念1：世界是公平的，出来混总要还
- "前面没经过融资困难，过得很顺，这几年就挺痛苦"——顺 11 年的账要补
- easy 模式的公司终要补 hard 模式的课；互联网高薪的账在 35 岁结算

#### 信念2：不变的东西优先于变化
- 面对 AI 焦虑的解法：先问什么不变（用户价值、价值链、创造者创造价值），"不变的底层越来越好，那不管什么变化，我都应该是更好的那一个"

#### 信念3：盯用户，不盯竞争
- "盯着竞争，最后跑出来的是一匹更快的马，而不是汽车"
- I 人性格 + 第一性原理的合流：不打听同行在干什么

#### 信念4：价值要分给创造价值的人
- 创造者拿七股东拿三；AI 提效的利润不默认流向 CEO；"切西瓜的人先拿"是历史规律，但他主动选择反着做——因为"长期要让价值循环跑起来"

#### 信念5：公司是作品（养娃），要活得比自己久
- 不打游戏因为"企业创造就是最有趣的游戏"；每天在公司刻意 ≤8 小时——第三类公司要靠体系跑，不靠 CEO 这里推一把那里推一把

**合成公式**：

```
抽象力 × 台阶节奏 × 双端锚定 × 分配正义 × 作品心态 = 一家想活过创始人的第三类公司
```

## IV. 思想的内在张力（直面矛盾）

### 张力1：不盯竞争 vs. 满口都是对标
- 一边说"永远不要盯着竞争"，一边整场在精确对标：拓竹是地狱模式、AirPods 是耳机七系的占位者、Ring 是三系上云安防、"跑得比同行快就行"
- **辨析**：他区分了"竞争定位"（战略输入，可以做）和"竞争驱动"（日常动作被对手牵引，不能做）。但这条线在组织里很难传导——高管能分清，一线容易滑向对标驱动。

### 张力2：第一性推演 vs. 大多数品类是"继承下来的"
- 做芯片是漂亮的第一性链式推演，但他自己承认"今天的大多数品类都是在有选择能力之前就做了，是被继承下来的"，见爱普生 CEO 时"很惭愧"
- **辨析**：第一性叙事是 2020 年后的回溯性重构——真实历史是直觉扩张在先、框架总结在后。他的坦诚（"这些定位都是事后归纳总结提出来的"）让这个张力可见，但也提醒读者：**框架是复盘工具，不是预测工具**。

### 张力3：存算一体的第一性必然 vs. 单一场景的商业验证
- 从范式推演，存算一体是端侧 AI 的必然；但 23 年 8 月立项到 26 年 5 月上市，近三年产出的第一个应用是"耳机通话降噪"——张小珺当场质疑"造了这么大的锤子，做了这么小的产品优化，值得吗"
- **辨析**：他的回答是"锤子系列的第一个锤子"+ 痛点真实。逻辑自洽，但深科技投入与浅海品类回报之间的时间差是真实风险——如果模型/芯片路线在三年内被通用方案（更强的低功耗 NPU）追平，自研的窗口就关了。

### 张力4：中层不会消失 vs. 组织会更精炼、SCRUM 会变小
- 用 context 论证中层永存，同时承认组织变精炼、部分 SCRUM 从十几人变几人、初级岗位减少
- **辨析**：他实际论证的是"中层的**职能**（context 压缩的价值选择、组织培育）不会消失"，不是"中层的**人数**不变"。两者常被混读——按他自己的逻辑，中层数量收缩与职能不可替代同时成立。

### 张力5：创造者拿七 vs. 决策权高度框架化于一人
- 分配上极度让利创造者，但战略框架、能力框架、组织框架、人才框架、回报设计、做哪些宏观品类——全部"是我决定的"
- **辨析**：他的"总统和联邦"模式里，总统保留修宪权。这与"分层授权"不矛盾（每层做每层的决策），但意味着安克的天花板仍然是阳萌本人的抽象质量——这也解释了他为什么把"公司是我的产品"挂在嘴边。

## V. 可复制 vs 不可复制

### ✅ 可复制（高迁移性）

| 方法 | 普通人如何用 |
|------|-----------|
| 1357 人群分层 | 做任何产品先问：我做的是几系？该人群愿付的价格带匹配吗 |
| 双端锚定扩张 | 换业务/换赛道前检查：新方向与我的既有用户、既有技能重叠度各有多高 |
| 台阶论 | 选择"当前能力够得着的下一阶"，而不是直接跳 nightmare |
| 三到五档量表法 | 把二元纠结（投不投/卖不卖/去不去）拉成 5 档光谱再选 |
| 下限思考 | 择业先算 35 岁时的下限，再看上限故事 |
| "什么不变"抗焦虑法 | 列出你所在行业 AI 改不掉的三件事，检查自己在这三件事上是否变强 |

### ❌ 不可复制（依赖阳萌的特殊条件）

| 方法 | 不可复制的原因 |
|------|------------|
| 顺 11 年再补课 | 2011 年亚马逊蓝海 + 中国供应链红利的时代窗口已关闭 |
| 自研存算一体芯片 | 需要五系现金流反哺深科技（数亿级投入）+ 300 人 AI 团队 |
| 妈妈 300 万天使 + 不缺钱创业 | "靠谱的事儿咱们用自己的钱做"——多数创业者没有这个起点 |
| 创造者拿七股东拿三 | 前提是 30% 总剩余价值——低毛利公司做不到这个分法 |
| 全员 AI、日耗 1500 亿 token 不算账 | "因为相信所以看见"需要年费数亿的支付能力 |

### ⚠️ 部分可复制（需要条件）

| 方法 | 复制条件 |
|------|--------|
| 预编排智能体（企业 AI 落地路径） | 需要先把业务数据"扫进系统"——硬件/传统企业的数据多数不在数字系统里，这是前置工程 |
| 五系转七系 | 需要在该品类具备"研发能力最强"的基础，且接受多年亏损期 |
| 总统和联邦模式 | 需要品类足够多——品类少的公司照搬会变成假放权 |

## VI. 三种角色的可执行启示

### 给硬件/消费电子创业者
1. 进品类前先算两笔账：这是几系市场（1357）+ 这是多大的盲注（浅海深海）——别拿浅海的钱上深海的桌
2. 扩张只走"人群重叠 × 技术栈重叠"的双高格子，其余机会写进观望清单
3. 智能化路线图对照"真智能三阶段"：你的产品还在"可调节"阶段的，就是被重做的对象——先于别人重做它
4. 深科技投入用第一性链式推演立项（痛点→模型→硬件瓶颈→缺口），并诚实评估通用方案追平的时间窗

### 给企业管理者 / CEO
1. 组织 AI 变革三板斧照抄：人拥抱 AI → 能力沉淀成预编排智能体（且跨领域拉通数据对象）→ 组织变革（SCRUM 缩小、岗位融合），按此排期
2. 别用"AI 消灭中层"叙事砍管理层——先问砍掉后谁做 context 压缩的价值选择、谁培育组织
3. 转型打不赢时先查价值观-人岗匹配，再查流程——"再好的阵法也要人去用"
4. AI 提效的利润分配提前立规矩（如 7:3），否则默认流向股东会瓦解"因为相信所以看见"的投入意愿

### 给个人（工程师 / 产品人）
1. 用"打仗次数"选平台：年轻时去仗多的地方（快速成熟），成熟后去一仗一两年的地方（长成长周期、弱 35 岁危机）
2. 判断自己做"大牛人"（造智能体：沉淀领域认知/数据/流程）还是"小牛人"（高效使用智能体）——前者稀缺，后者是底线要求
3. 学阳萌的抽象习惯：看到惊艳的事物，写下它背后的原理，再迁移到自己的领域——每周一次
4. 面试/自查用创造者三问：最近一次第一性思考是什么？最近一次顶着风险把事做出来是什么？出问题时先找自己的部分了吗？

## VII. 分析方法说明

本分析采用 **Self-Debate 5 轮迭代**：

1. **Round 1 生成**：领域专家视角直接输出初稿（12 观点 + 3 层挖掘）
2. **Round 2 逻辑批评**：检查框架叙事与真实历史的先后关系、张力辨析是否偷懒
3. **Round 3 受众批评**：以硬件创业者/企业管理者视角评估可执行性
4. **Round 4 改进**：综合批评意见重写
5. **Round 5 评分**：3 维度打分（完整性 / 逻辑 / 受众价值）

**本篇特有的局限性**：

1. **框架叙事的回溯性**：阳萌自认多数框架（1357、浅海深海）是"事后归纳"，本分析尽量在张力 2 中标注，但读者仍需警惕把复盘框架当预测工具
2. **雇主品牌语境**：他明说"来节目最主要的目的是吸引更多人加入"——关于分配（7:3）、收入（+20%/年）、平台价值的表述带招聘动机，未经第三方验证
3. **ASR 错误密集**：B 站自动字幕将"阳萌"识别为"杨萌"、拓竹为"拓主/兔子/拓者"、爱普生为"艾弗森"、Jeff Dean 为"JEFFIN"、Scrum 为"死光/司法/SCP"、《领导梯队》为"领导阶梯"等，已人工纠正；个别专名（如启发其组织变革的 spec 工作流工具名、其 UT Austin 导师名）无法从字幕确认，行文从略
4. **单方陈述未经验证**：内部 token 用量、安防全球第二、召回决策过程等均为嘉宾单方说法
5. **二阶失真**：本文为字幕→分析的二次加工，请以原视频为准
